`j3c doc j2` — j2 scripts: mods the game reads at runtime

j2 is a scripting language for people without the source: players, modders, designers. A
`.j3s` script is compiled by `j3c`, so a shipped game can't take new ones. A `.j2` file is plain
text the game itself reads, compiles, and runs while it plays. It looks like J3 (`let`, `fn`,
`{ }`, backtick strings, `match`, `use`, `pub`) and behaves like Lua (values carry their types,
tables, closures, a GC). All of it (lexer, parser, compiler, VM, heap) is J3 in `j3.j2`, with no
window or C library, so it works in a console program and on every target.

`j3c doc j2 lang` is the language on one page, written for script writers: ship it with your
game, then add your own hooks and natives below it. `j3c doc recipes j2` is the smallest host;
`examples/j2_script` is a whole game whose content is scripts (reload on save, one script's
error disables only that script). Names: `j3c doc j3.j2 --short`.

## Host API

```j3
use j3.j2;
use j3.j2.{ Vm, Limits, Args, Value, Ref, Error, Table };   // J3 can't write `j2.Vm` as a type

let vm = Vm.new(&mem, Limits { heapBytes: 32 << 20, stepsPerCall: 500000 });   // maxDepth: 200 too
vm.openLibs(j2.LIB_BASE | j2.LIB_MATH | j2.LIB_STRING | j2.LIB_ARRAY);  // or j2.LIB_ALL
vm.host = w as ptr;                          // natives get it back with `vm.host as &World`
vm.bind("spawn", spawn);                     // fn spawn(vm: &Vm, args: Args): Value
vm.bind("print", print);                     // a bind replaces a built-in (print to the screen)
vm.seed(1234);                               // pick/rand/math.random sequence (replays, tests)
vm.resolver = resolveUse;                    // fn(ctx: ptr, vm: &Vm, name: string): Value, for `use name;`
vm.resolverCtx = ctx as ptr;

match vm.loadFile("slimes", "mods/slimes/main.j2") {   // read, compile, run the top level
    Result.Ok(exports) { let r = vm.keep(exports); }    // vm.loadString(name, text) for any text
    Result.Err(e) { e.message; e.chunk; e.line; e.col; e.trace; }
}
vm.call(f, [j2.num(dt)]);                    // Result<Value, Error>; j2.noArgs() for none (no `[]` in J3)
vm.callWithThis(f, self, args);              // binds `this` when f's first parameter is `this`

let r = vm.keep(v);  vm.value(r);  vm.get(r);  vm.release(r);   // GC roots the host holds
vm.getNum(r, "x");   vm.setNum(r, "hp", 3.0);                  // f32 field access on a kept table
vm.get(r).getNum("color", 0.0)               // f64: exact for ints such as colors (f32 is not)
vm.newTable();  vm.newArray(n);  t.set(k, v);  t.get(k);  t.merge(o);  t.getNum(k, d);  t.getStr(k, d);
v.asTable()  v.asStr()  v.asNum()  v.isNil()  v.truthy()
args.num(i)  args.int(i)  args.str(i)  args.table(i)  args.func(i)  args.numOr(i, d)  args.intOr(i, d)
args.get(i)  args.count()  args.joined(sep)
vm.raise("message")                          // a script error at the caller's line: `return vm.raise(..)`
vm.intern(s)                                 // a string that lives as long as the VM (names the host keeps)
j2.nil()  j2.none()  j2.num(x)  j2.int(n)  j2.boolean(b)  j2.str(vm, s)
vm.stats()                                   // liveObjects, bytes, collections (a debug HUD)
vm.destroy()                                 // all script memory back; the Vm is unusable after
```

`args.func` is `fn` in other languages; `fn` is a J3 keyword. `LIB_BASE` is `print error len type
str int float`, `LIB_ARRAY` `push pop insert remove pick map filter find sort join keys has`,
`LIB_STRING` `upper lower trim split contains slice`, `LIB_MATH` `rand` and the `math` table.
A name the host binds wins over a built-in, before or after `openLibs`.

## Rules

- Order: `openLibs` and every `bind` before the first load. A script's names are checked when
  it loads, so a name bound later is an `unknown name` error. Binding a name again replaces it,
  also for scripts already loaded.
- One `Vm` per thread. A `Vm` and its values belong to the thread that made it; natives run on
  that thread. Two threads that both run scripts make two VMs.
- Errors never panic: every entry returns `Result<_, Error>` and the `Vm` keeps working after
  any error, a parse error, a runtime error, `out of script memory`, `took too long (over N
  steps)` (`Limits.stepsPerCall`, so `while true {}` can't freeze the game) or `stack overflow`
  (`Limits.maxDepth`).
- Error text: `e.message` reads ``mods/slimes/main.j2:14:9: expected `}`, found end of file``. It
  and `e.trace` are valid until the VM's next error, so copy them into a `j3.text.Text` before
  any other VM call. `e.chunk` (the name given to `loadFile`) stays valid. It names the script
  whose code raised, so the host can disable that one.
- Natives: `fn(vm: &Vm, args: Args): Value`. The argument getters raise a script error on a
  wrong type, so natives don't check types. Read every argument before any side effect, so a
  wrong one changes nothing; `vm.raised` says whether one already failed. `vm.call` from a native
  is fine (re-entrant).
- Keep: `vm.newTable`, `newArray` and `j2.str` results stay alive until the running native
  returns (outside a native: until the current top-level call ends). `keep` anything the host
  holds longer (exports tables, entity tables, callbacks), and `release` it when done. A
  `vm.call` result held in a J3 local across another call needs `vm.protect(v)`.
- Numbers: `vm.getNum` / `setNum` are `f32`, fine for positions. Read int fields (colors, ids,
  counts) with `vm.get(r).getNum(k, d)` (f64), exact up to 2^53. `args.num` is f64,
  `args.int` an int.
- Reload: each `loadFile` / `loadString` is a fresh module (new top-level variables, new exports).
  To reload, `release` the old exports and every `Ref` to their functions, then load again.
  Tables the host kept (enemies) survive and find their new code by name (store the kind's
  name, look it up in the new exports). `onStart`-style hooks are the host's to call again.
- `use name;` in a script calls `vm.resolver(ctx, vm, name)`, which returns that script's exports
  table (load it first if needed) or `vm.raise(..)`. The default resolver fails every `use`.
  A cycle (`a` uses `b` uses `a`) is an error.
- Determinism: `pick`, `rand` and `math.random` use the VM's own generator. `vm.seed(n)` makes
  a run repeat (replays, tests). Don't bind your own `rand`.
- J3 backtick strings hold at most 512 bytes and live in their frame: never put script text
  in one. Build messages with `Text.scratch().add(..)` or a `Text` you own.
- Scripts see only what you bind. With no natives for files, network or processes, a mod
  can't reach them.

## Not yet

Coroutines (`wait(1.5)` style scripts), metatables or operator overloading, `try`/`catch`
inside j2, sharing one `Vm` across threads, a bytecode cache, state kept across a reload.

## Language (for script writers)

This section is the j2 language for people writing scripts. Ship it with your game (as
`SCRIPTING.md`, say) and add your game's hooks and functions after it, the way
`examples/j2_script/SCRIPTING.md` does. Built-ins that the game didn't open
(`vm.openLibs`) or replaced (`vm.bind`) differ.

j2 looks like J3 and works like Lua. You don't write types, because values carry their own.

```
// a comment
let hp = 10;           // a variable
const MAX = 3;         // a variable that can't change
hp += 1;

let name = "slime";
print(`{name} has {hp} hp`);       // backtick strings fill in {expressions}
print("plain " + name);            // + joins strings
print("\e[31mred\e[0m \u{2665}");   // escapes: \n \t \r \0 \\ \" \{ \e (ESC), \xHH (a byte), \u{HHHH} (UTF-8)
let fish = r"
 |\ /  o
 |/ \__/
";                                 // raw string: no escapes, may span lines, newlines kept
let lines = split(fish, "\n");     // ["", " |\ /  o", " |/ \__/", ""]
let q = r#"say "hi""#;             // r#"..."# lets a " in (more #s for "# inside)

let p = { x: 1, y: 2 };            // a table: names -> values
p.z = 3;                           // add a field
p.z = nil;                         // remove it
print(p.w);                        // a missing field is nil, not an error

let xs = [10, 20, 30];             // an array; the first element is xs[0]
xs.push(40);
print(len(xs));                    // 4

if hp > 5 && name != "grunt" { } else if !done { } else { }
while hp > 0 { hp -= 1; }
for i in 0..3 { }                  // i = 0, 1, 2
for v in xs { }                    // each value
for i, v in xs { }                 // index and value
for k, v in p { }                  // each field name and value, in the order they were added
// break and continue work in loops

match n {                          // compare against ints, strings, true/false
    1 { }
    "two" { }
    _ { }                          // anything else
}

fn add(a, b) { return a + b; }     // a function; without `return` it gives nil
let half = fn(v) { return v / 2; };          // a function stored in a variable
let counter = fn() {
    let n = 0;
    return fn() { n += 1; return n; };       // remembers n between calls
};
```

Good to know:

- **True and false:** only `nil` and `false` count as false. `0` and `""` count as true.
- **Numbers:** there are ints (`3`) and floats (`3.0`, `1e9`). An int divided by an int
  gives an int (`7 / 2` is `3`). If either side is a float, the result is a float
  (`7.0 / 2` is `3.5`). `float(x)` and `int(x)` convert.
- **`this`:** writing `obj.f(a)` hands `obj` to `f` as `this`, but only when `f`'s first
  parameter is named `this`. Otherwise it's a plain call. That's how you write methods.
- **Dot calls:** when `x` has no field `f`, `x.f(a)` means `f(x, a)`. So `xs.push(v)` is
  `push(xs, v)` and `name.upper()` is `upper(name)`.
- **Private and shared:** the top-level names in your file belong to your script. Put `pub`
  in front of a `fn`, `let` or `const` to share it. The game calls your `pub fn`s.
- **Other scripts:** `use base;` gives you base's `pub` names, for example `base.chase(e, dt)`.
- **Typos:** a name that doesn't exist (`spwan(...)`) is an error as soon as the script
  loads, with its line. A missing *field* is just `nil`.
- **Errors:** `error("message")` stops your script and shows the message. A loop that never
  ends does the same after a moment, so it can't freeze the game.
- **Reloading:** loading a script again runs it from the top. Its top-level variables start
  over.

Built-ins:

| Name | Does |
|---|---|
| `print(a, b, ...)` | Writes the values on one line |
| `len(x)` | The size of an array, string or table |
| `type(x)` | `"nil"` `"bool"` `"int"` `"float"` `"string"` `"array"` `"table"` `"fn"` |
| `str(x)` `int(x)` `float(x)` | Convert |
| `error(msg)` | Stop with an error |
| `push(a, v)` `pop(a)` `insert(a, i, v)` `remove(a, i)` | Change an array |
| `pick(a)` | A random element, or nil when empty |
| `rand(lo, hi)` | A random float from `lo` up to (not including) `hi` (also `math.random(lo, hi)`) |
| `map(a, f)` `filter(a, f)` `find(a, f)` `sort(a)` `sort(a, less)` `join(a, sep)` | A new array, the first match, sort in place (`less(x, y)` decides the order; default `<`), text with `sep` between values |
| `keys(t)` `has(t, name)` | A table's field names; whether it has a field |
| `upper(s)` `lower(s)` `trim(s)` `split(s, sep)` `contains(s, part)` `slice(s, from, to)` | Text |
| `math.pi` `math.sqrt` `sin` `cos` `tan` `atan2` `abs` `floor` `ceil` `min` `max` `clamp` `lerp` `random` | Math, e.g. `math.clamp(v, 0, 1)`. `floor` and `ceil` give ints; `abs` `min` `max` `clamp` keep ints ints |
