The smallest j2 host: a console program, no window. It makes a VM, binds one native, loads a
mod from `mods/hello.j2`, calls its `pub fn onTick` three times, reads its `pub let speed`, and
shows the error a typo gives. Run it with `j3c run`; it prints `tick 1: slime at x=10.0`,
`onTick gave 1`, ... `speed = 2.5`, then ``broken:1:21: unknown name "spwan"``.

- Order: `openLibs` and every `bind` come before loading. A script's names are checked when
  it loads, so a name bound later is an `unknown name` error.
- `loadFile` / `loadString` run the top level and give the exports table (the `pub` names).
  `keep` it: a `Ref` is a GC root until `release`. Values the host holds in J3 locals across
  calls are not roots.
- `vm.call(f, [j2.num(x)])` returns `Result<Value, Error>`. Use `j2.noArgs()` for none.
- `e.message` reads `chunk:line:col: text` and lasts until the VM's next error. Copy it into a
  `j3.text.Text` to keep it. The VM keeps working after any error.
- A native is `fn(&Vm, Args): Value`. `args.str/num/int/table/func(i)` raise a script error on
  a wrong type; `return vm.raise("...")` raises your own.
- `j3c doc j2` is the host guide, `j3c doc j2 lang` the language page to give modders, and
  `examples/j2_script` a whole game whose content is scripts (reload on save, per-script errors).
