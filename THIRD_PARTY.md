# Third-party material and asset provenance

J3 itself (compiler, stdlib, editor, tools, examples, docs) is licensed under
**MIT OR Apache-2.0** (`LICENSE-MIT`, `LICENSE-APACHE`), copyright 2026 Jacoby-Y and J3 contributors.

This file lists what in the tree is **not** original J3 work, and where every binary asset comes from.
Globs are relative to the repo root; `**` is any depth.

## Games you build with J3

A program built with `j3c` links parts of the J3 stdlib and runtime (`j3c/stdlib/`) into its
binary. That binary is yours: ship it under any license, open or closed, sold or free. The
MIT/Apache-2.0 terms allow this. Keeping a copy of the MIT notice with what you ship is enough, and
a line in your credits or a bundled text file does it.

What you ship next to the binary has its own licenses:

| Thing | When it ships | License | What it asks |
|---|---|---|---|
| SDL2, SDL2_image, SDL2_mixer, SDL2_ttf | Windows zip (DLLs copied by `j3c build`), Android apk (built by `tools/android/build-sdl.sh`) | zlib | Nothing in binary form. The image/mixer/ttf DLLs bundle further libraries (FreeType, libpng, libjpeg, zlib, libogg/vorbis, ...); their license files come in the SDL mingw dev kits, ship them with the DLLs |
| OpenSSL 3 (`libssl.so.3`) | Android apk with `j3.net.http` (`tools/android/build-openssl.sh`) | Apache-2.0 | Include its license text |
| `libsteam_api.so` / `steam_api64.dll` | Steam depot (`[dist] build_outputs = ["steam"]`), copied from your own SDK | Steamworks SDK Access Agreement (Valve) | Redistributable under that agreement only |
| DejaVu Sans (`assets/font.ttf` written by `j3c new --template ui`) | Any game that keeps it | Bitstream Vera + Arev (permissive) | Keep its license text with it: `j3c new` writes `assets/LICENSE-DejaVu.txt` next to the font |

## Code and data inside `j3c`

| Path | What | Source | License |
|---|---|---|---|
| `j3c/src/ui/icons/bootstrap.txt` | Bootstrap Icons path data (`<icon name=...>`), embedded in the binary | https://icons.getbootstrap.com | MIT, text in `j3c/src/ui/icons/LICENSE` |
| `j3c/editor/font.ttf` | DejaVu Sans, embedded in the binary (editor UI font, copied into new projects by `j3c new`) | https://dejavu-fonts.github.io | Bitstream Vera + Arev, `j3c/editor/LICENSE-DejaVu.txt` |
| `j3c/stdlib/j3/term/width.j3` | Terminal column widths | Generated by `tools/gen_wcwidth.py` from Python's `unicodedata` (Unicode Character Database) | Project license; derived from Unicode data (Unicode License v3, permissive) |
| `j3c/stdlib/j3/steam/**`, `j3c/src/steamcheck/**` | Steamworks bindings and binding checker | Hand-written: functions are looked up by name with `dlopen` at run time, nothing links Valve code. `steamcheck` reads the headers of the SDK the user passes with `--sdk` | Project license. No Valve SDK file or header copy is tracked (`git ls-files \| grep -i steam` lists only J3 sources and docs); `steamcheck/tests.rs` has a few one-line declarations in the `steam_api_flat.h` style as test input |

Build scripts that download third-party code at build time (nothing is vendored):
`tools/fetch_sdl2_mingw.sh` (SDL2 mingw dev kits, zlib), `tools/android/build-sdl.sh` (SDL2 sources, zlib),
`tools/android/build-openssl.sh` (OpenSSL, Apache-2.0). `j3c/src/online.rs` (editor/MCP `asset_fetch`)
downloads into the user's project from Poly Haven, ambientCG, and Kenney, all CC0, and writes a
`CREDITS.txt` line per asset.
